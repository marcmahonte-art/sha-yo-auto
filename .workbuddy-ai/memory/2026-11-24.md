## Showroom : chevauchement des voitures + responsivité mobile (13:05)
- Diagnostic : dans `renderAll()` (mode `ring`), l'opacité ne dépendait que de l'angle (`(cos φ + 0.55) / 0.3`), donc les modèles situés **derrière** l'anneau (k≥2) restaient à opacité 1. Ils se projetaient au centre et empilaient 3-4 silhouettes sombres floues autour de la voiture active. En plus la voiture était collée en bas (`--rw-hy: 34px`) → 203 px de vide au-dessus en 1440, 280 px sur iPhone.
- `src/main.ts`, mode ring : opacité `clamp(1 - 0.5*sl, 0, 1)` (un seul voisin par côté, à 50 %), échelle `persp * (1 - 0.28*sl)` (les voisines sont nettement plus petites), `R` 0.62W → 0.78W, flou 1.8 → 2.4. Centrage vertical : `floor = min(H-34, max(H*0.42, (H+heroH)/2))` et `--rw-hy = max(34, (H - modelH*fs)/2)`.
- `capW` progressif pour la taille de la voiture selon la largeur de scène : 0.86 (<520 px), 0.7 (<760 px), 0.56 au-delà. Corrige la voiture minuscule sur tablette 768.
- Mobile (`mode classic`) : largeur 0.84W → 0.94W. `src/runway.css` : `.rw__sticky { height: auto }` + `.rw__stage { flex: 0 0 auto; height: calc(var(--rw-model-h) + 64px) }` dans `@media (max-width:749px)`. La scène épouse la voiture → plus de vide, et les commandes restent visibles.
- Ajout d'un `@media (min-width:750px) and (max-height:560px)` (téléphone en paysage) qui compacte l'en-tête (sous-titre masqué, titre 28px). Plancher de `--rw-frame-h` 380 → 280 px pour que la barre de modèles tienne dans le viewport.
- Piège rencontré : le serveur du port 3000 sert `dist/` (build), pas les sources → les premières mesures ne bougeaient pas. Utiliser `npx vite --port=3100` pour itérer.
- Vérifié Playwright : 6 modèles, 0 erreur console, 0 requête >=400, `hscroll=0` sur les 5 pages en 1440 et 393 ; lightbox et page d'accueil intactes ; `tsc --noEmit` et `npm run build` OK. Captures avant/après dans `apercus/comparaison-desktop.png` et `apercus/comparaison-mobile.png`.
